测量边界与状态说明

计时使用 performance.now()。到 headers 包含 fetch 调用到响应头交给 JavaScript 的时间；到首块、完整 body 和结束分别记录。已读字节仅指交给 JavaScript reader 的响应体字节，不含 HTTP 头及其他传输开销。完整有效样本的 body_KiB_s 使用这些字节除以 headers 到 EOF 的时间；浏览器解码和缓冲会影响此值，它不是线上压缩后字节的速率。压缩控制与线上字节量须通过 Caddy 配置和 CDP 核实。

“最大观察读间隔”包括 headers 到首块、相邻有数据块，以及末块到 EOF/失败/中止的等待。另记录只计算相邻有数据块的最大间隔。JavaScript 数据块不是 TCP 包；调度、解压、页面冻结都可能影响这些值，不能单靠本页判断网络丢包。未配套 CDP 时，不具备同时段的并发请求、协议或远端 IP 证据。

aborted_timeout 表示本页 30 秒计时器触发中止；user_cancelled 表示手动停止。两者都保留此前已读字节。浏览器冻结或挂起时计时器可能延后，JSON 会记录实际中止时间。

只接受 HTTP 200、二进制 Content-Type 和精确长度；HTML 登录页不会计为成功。重定向会被拒绝。鉴权由浏览器同源携带；探针不读取或导出 Cookie，也不访问聊天数据。JSON 仅保存人工标签、计时、计数和指定诊断响应头，不保存测试文件字节。CDP 与服务端日志须在本页之外采集。

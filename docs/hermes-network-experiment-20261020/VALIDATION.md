## 固定字节生成器与诊断页

生成器校验了语法、确定性、SHA256、难压缩内容、同内容重跑保留、冲突及符号链接拒绝。

诊断页进行了 JS 语法与模拟响应检查：完整成功、200 HTML 登录页、HTTP 错误、重定向、长度异常、部分读取后失败、超时、手动停止、默认 72 KiB 顺序和 JSON 导出。已收到的部分字节不会因失败丢失。

页面记录 reader 字节、不是 wire 字节；CDP／实际编码信息需要真实部署时并行采集。未完成真实浏览器渲染检查、手机 E2E、首尔端部署验证或 Wi‑Fi／蜂窝新路径测量，均留作本机执行阶段。
